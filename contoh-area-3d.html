Pilih area 3D untuk Gilbert

Tarik file nota (foto atau Excel) ke salah satu area, atau tekan "Coba". Bisa juga diputar dengan jari atau mouse.

ATarik file nota ke sini

Keranjang pasar

File dilempar ke keranjang, lalu bahan-bahan melompat keluar sebelum berubah jadi daftar belanja.

BTarik file nota ke sini

Peti kayu bercahaya

Tutup peti terbuka saat file didekatkan, menelan file, lalu memancarkan cahaya tosca ke Xander.

CTarik file nota ke sini

Truk pengantar

File dimuat ke bak truk, lalu truk melaju keluar layar membawanya ke Xander.

Contoh tampilan saja: file tidak dibaca dan tidak dikirim ke mana pun.
